## 📖 Sobre o projeto

O **Projeto Login** é uma interface de autenticação desenvolvida para praticar conceitos fundamentais de desenvolvimento Front-end.

A aplicação apresenta uma tela de login limpa e moderna, permitindo ao usuário visualizar campos para e-mail e senha, opção para permanecer conectado, recuperação de senha e alternativas de autenticação.

O layout foi desenvolvido utilizando uma abordagem responsiva, adaptando a interface para diferentes tamanhos de tela, como:

* 📱 Smartphones
* 📱 Tablets
* 💻 Notebooks
* 🖥️ Desktops

O principal objetivo do projeto foi colocar em prática conhecimentos relacionados a **HTML semântico, formulários, estilização com CSS, Flexbox, CSS Grid e Media Queries**.

## 📱 Responsividade

O projeto foi desenvolvido seguindo uma abordagem responsiva, adaptando sua estrutura conforme o tamanho da tela.

### 📱 Mobile

Em telas menores, o formulário ocupa a área principal da página, priorizando uma navegação simples e confortável.

### 📱 Tablet

A partir de aproximadamente `768px`, o formulário passa a possuir uma largura máxima, mantendo o conteúdo centralizado.

### 🖥️ Desktop

A partir de aproximadamente `1024px`, o layout é dividido em duas colunas:

```text
┌─────────────────────┬─────────────────────┐
│                     │                     │
│     Ilustração      │      Formulário     │
│                     │       de Login      │
│                     │                     │
└─────────────────────┴─────────────────────┘
```

Essa organização melhora a utilização do espaço disponível em telas maiores.
